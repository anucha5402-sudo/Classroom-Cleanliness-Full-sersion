# ระบบให้คะแนนความสะอาดห้องเรียน — โรงเรียนดารุสสลามวิทยา

จัดทำโดย **องค์การบริหารกิจการนักเรียนโรงเรียนดารุสสลามวิทยา**

## โครงสร้างไฟล์

```
classroom-cleanliness/
├── index.html          หน้าเว็บหลัก
├── style.css            สไตล์และธีมสี (โทนฟ้า-ขาว)
├── script.js             เกณฑ์คะแนน, การคำนวณ, การเชื่อมต่อฐานข้อมูล
├── firebase-config.js    ค่าตั้งค่าฐานข้อมูลกลาง (ต้องกรอกเอง — ดูขั้นตอนด้านล่าง)
├── assets/
│   ├── logo-school.png   ตราโรงเรียน
│   └── logo-council.png  ตราองค์การบริหารกิจการนักเรียน
└── README.md
```

## เปิดใช้งานแบบง่าย (ทดสอบในเครื่อง)

ดับเบิลคลิกเปิด `index.html` ในเบราว์เซอร์ หรือใช้ Live Server ใน VS Code ได้เลย
ถ้ายังไม่ได้ตั้งค่า Firebase (ขั้นตอนด้านล่าง) ระบบจะขึ้นป้าย **"โหมดออฟไลน์"**
และเก็บข้อมูลไว้ในเบราว์เซอร์เครื่องนั้นเท่านั้น (เหมือนเวอร์ชันก่อนหน้า) —
ใช้งานได้ปกติทุกฟีเจอร์ เหมาะสำหรับทดลองระบบก่อน

## ตั้งค่าฐานข้อมูลกลางด้วย Firebase (สำหรับใช้งานจริง หลายคนหลายเครื่อง)

เพื่อให้ผู้ตรวจหลายคนกรอกข้อมูลจากคนละเครื่อง แล้วทุกคนเห็นภาพรวมร่วมกันได้จริง
(รวมถึงเปิดดูจากเว็บไซต์โรงเรียนได้) ต้องเชื่อมต่อฐานข้อมูลกลาง — เราแนะนำ
**Firebase Firestore** ของ Google เพราะใช้ฟรี ไม่ต้องเช่าเซิร์ฟเวอร์เอง
และตั้งค่าเสร็จใน 10-15 นาที

### ขั้นตอนตั้งค่า

1. ไปที่ https://console.firebase.google.com แล้วล็อกอินด้วย Google Account ของโรงเรียนหรือของทีมงาน
2. กด **"Add project"** ตั้งชื่อโปรเจกต์ เช่น `darussalamwitya-cleanliness` แล้วกด Continue จนสร้างเสร็จ
   (ปิดการใช้ Google Analytics ก็ได้ ไม่จำเป็นสำหรับงานนี้)
3. ในเมนูซ้ายเลือก **Build > Firestore Database** กด **Create database**
   เลือกโหมด **Start in test mode** ก่อน (แก้กฎความปลอดภัยทีหลังได้) เลือก location
   ที่ใกล้ที่สุด (เช่น `asia-southeast1`) แล้วกด Enable
4. กลับไปหน้าโปรเจกต์หลัก กดไอคอนรูปฟันเฟือง > **Project settings**
   เลื่อนลงมาที่ **"Your apps"** กดไอคอน **</>** (Web) เพื่อสร้างเว็บแอป
   ตั้งชื่อ (เช่น `cleanliness-web`) แล้วกด **Register app**
5. Firebase จะโชว์ก้อนโค้ด `firebaseConfig = { apiKey: "...", ... }` ให้ **คัดลอกค่าทั้งหมด**
6. เปิดไฟล์ `firebase-config.js` ในโปรเจกต์นี้ แล้ววางค่าที่คัดลอกมาแทนที่
   ค่าตัวอย่าง (`"วางค่าของคุณที่นี่"`) ให้ครบทุกช่อง แล้วบันทึกไฟล์
7. เปิด `index.html` ใหม่อีกครั้ง ถ้าตั้งค่าถูกต้องป้ายจะเปลี่ยนเป็น
   **"เชื่อมต่อฐานข้อมูลกลาง"** สีเขียว/ฟ้า แสดงว่าใช้งานได้แล้ว

### ตั้งกฎความปลอดภัย (Firestore Rules)

โหมด "test mode" จะหมดอายุอัตโนมัติใน 30 วัน ต้องตั้งกฎถาวรเอง
ไปที่ **Firestore Database > Rules** แล้ววางกฎนี้แทนของเดิม:

```
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /data/{document} {
      allow read: if true;
      allow write: if true;
    }
  }
}
```

กฎนี้เปิดให้ทุกคนอ่าน/เขียนได้ (เหมาะกับเครื่องมือภายในโรงเรียนที่ไม่ได้เก็บข้อมูล
ส่วนตัวที่ละเอียดอ่อน) ตัวระบบเองมีรหัสผ่านกันไว้ชั้นหนึ่งอยู่แล้วสำหรับหน้ากรอกข้อมูล
ถ้าต้องการความปลอดภัยเข้มขึ้นในอนาคต (เช่น ผูกกับบัญชีครูแต่ละคน)
สามารถเพิ่ม Firebase Authentication ภายหลังได้ — เป็นงานคนละขั้นที่ทำเพิ่มได้

## นำขึ้นเว็บไซต์โรงเรียน

เมื่อตั้งค่า Firebase เสร็จแล้ว ไฟล์ทั้งหมดในโฟลเดอร์นี้เป็น **เว็บไซต์แบบ Static**
(ไม่ต้องมีเซิร์ฟเวอร์พิเศษ) อัปโหลดได้หลายวิธีแล้วแต่ระบบเว็บไซต์โรงเรียนที่มีอยู่:

- **มี Hosting/cPanel อยู่แล้ว**: อัปโหลดไฟล์ทั้งโฟลเดอร์ผ่าน File Manager หรือ FTP
  ไปไว้ในโฟลเดอร์ย่อย เช่น `public_html/cleanliness/` แล้วเข้าผ่าน
  `https://โดเมนโรงเรียน/cleanliness/`
- **ไม่มี Hosting หรืออยากได้ลิงก์แยกฟรี**: ใช้ **Firebase Hosting**
  (ฟรี อยู่ในระบบเดียวกับฐานข้อมูลที่ตั้งไว้แล้ว) หรือ **Netlify** / **GitHub Pages**
  ก็ได้ — ลากโฟลเดอร์นี้วางบนเว็บของผู้ให้บริการได้เลย ไม่ต้องตั้งค่าเพิ่ม
- จากนั้นนำลิงก์ไปแปะไว้ในเว็บไซต์หลักของโรงเรียน (เช่น ทำเป็นเมนูหรือปุ่มลิงก์)
  ให้ครู/นักเรียน/ผู้ปกครองเข้ามาดูภาพรวมได้จากปุ่ม "ดูภาพรวมคะแนน" โดยไม่ต้องมีรหัสผ่าน

(รหัสผ่านนี้ใช้ร่วมกันสำหรับผู้มีสิทธิ์ตรวจทุกคน ไม่ใช่รายบุคคล)

## เกณฑ์คะแนน (สรุป)

คะแนนเต็ม 100 ต่อห้อง หักตามระดับ 1-5 ในแต่ละหัวข้อ (พื้นห้อง / ขยะใต้โต๊ะ /
ขยะบนโต๊ะ / เก้าอี้ / โต๊ะ / พัดลม) และมีการหักคะแนนพิเศษเพิ่มเติมกรณีพบ
ความเสียหายรุนแรง (ต้องกรอกหมายเหตุก่อนเลือกระดับความรุนแรง)

ระดับรายสัปดาห์คำนวณจากคะแนนเฉลี่ยของห้องในสัปดาห์นั้น:

| คะแนนเฉลี่ย | ระดับ |
|---|---|
| 90 ขึ้นไป | ผ่านเกณฑ์ดีเยี่ยม |
| 75 - 89 | ผ่านเกณฑ์ |
| 50 - 74 | ควรปรับปรุง |
| ต่ำกว่า 50 | ต้องปรับปรุงโดยด่วน |
